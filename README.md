# Crimson Ascent GitHub Pages Site

This is a cleaned static rebuild of the original Bluehost/WordPress landing page.

## Files kept
- `index.html`
- `styles.css`
- `assets/` images used by the page

## Removed
- WordPress-generated markup and scripts
- Bluehost / suspended-page dependencies
- analytics, trackers, feeds, oEmbed, and plugin references
- placeholder footer links that pointed nowhere

## Publish on GitHub Pages
1. Upload all files in this folder to the root of your repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch (usually `main`) and the `/ (root)` folder.
5. Save.

GitHub Pages will serve `index.html` automatically.
